# Melee Ruleset

The rules package of the melee game from the design documents: each player owns one hero, an identical Nexus, and a set of buildings that raise an autonomous army from their own mana. It authors rules, not a board.

## Referenced by the board

The `ugc-SecludedCrest` repository is the composing map: its `references.json` names this map, and every save of it takes this map's files into its own folder, so the board becomes one ordinary playable map. Nothing has to be composed here, and this folder is never the map that is played.

| Into | What this map contributes |
| :--- | :--- |
| Secluded Crest v1.0.0 | `MapScript.cs`, the rules script itself, and the melee templates this map's `metadata.json` declares - units, buildings, abilities, relics and the two harvestable resource node types - plus the factions, deck and economy the script runs. |

## The board supplies the placement

This map declares no `terrain.json` and no coordinates of its own. Where the twelve resource nodes stand and where each seat begins are the board's statements, so any board authored for Melee plays by these rules unchanged:

* The four starting points are `SpawnAnchors` in the board's `terrain.json`, one per player slot. The script reads slot *n*'s point with `IGameAPI.GetSpawnAnchor(n)`, places that player's Nexus on it, and puts the hero beside it. A board with no anchor for a slot seats nobody there and says so in that player's feedback rather than inventing a position.
* The twelve resource nodes are props the board places with the template ids this map declares (`resource/melee_gold_mine` and `resource/melee_woodland`). The engine attaches the node's capacity from the template when the prop loads, so the script spawns nothing and only reads the layout, through `IGameAPI.GetResourceNodes`.
* A board that declares no anchors or places no nodes is not a Melee board. The script warns the table once at the start of a match instead of seating players somewhere arbitrary.

`metadata.json` here is merged into the board's: objects merge key by key, arrays are combined with each entry kept once by its `TemplateID`, and the board merges last, so the board's own identity, build number, shroud and camera stand while the rules, units, abilities and relics arrive from here.

Every other file comes whole from exactly one map. `MapScript.cs` is the one file the board's `references.json` states comes from this map, because the ruleset is defined here; `MapScript.csproj`, the generated templates, `Directory.Build.targets`, `NuGet.config`, `AGENTS.md`, `LICENSE.md` and `.gitignore` are kept by the board, which builds and maintains its own copies. `MapTemplates.g.cs` and `WasmEntryPoint.g.cs` are never taken from a referenced map at all.

### Prerequisites

* The board reads this map from `FolderPath` in its `references.json` while that folder exists, and otherwise from the map store by name, version and this map's pinned manifest hash.
* `manifest.json` here is the package manifest that pin names. Regenerate it with `MapManifest.CreateFromDirectory` whenever this map's content changes, then repin the board's reference to the new `ComputeManifestBlake3()`. The generated workspace code (`MapTemplates.g.cs`, `WasmEntryPoint.g.cs`) is not part of the manifest, because the editor rewrites it from the merge on every setup and the hash would otherwise move the pin without this map's content changing.
* `lib/` and `bin/` are this map's own workspace. The board compiles its script in its own folder from the files it takes, so the `.wasm` the game runs is never the one built here.

## What the script implements

* **One hero per player.** The lobby's faction dropdown selects Vale, Sable or Corvus, or Random, which the authority resolves to one of the three when it seats the match; the hero spawns beside an identical Nexus at the board's anchor for that slot. Every player starts with 200 gold and 100 wood.
* **Army level.** Every living soldier is set to the hero's level, which is the only source of army stat growth, and each hero carries its own per-level growth: Vale's levels buy health and weapon damage, Sable's buy spell power and its supporting intelligence attributes, and Corvus's buy Fortune - critical strikes, evasion and proc rate.
* **Formations and targeting.** Each soldier type holds its authored slot around the hero, rotating with the hero's facing - Front ahead, Flank to either side, Back behind - and fights by its authored rule: Standard concentrates on the target the hero last hit, Tank-Shredder takes the healthiest enemy in range, and Assassin the weakest. Slot and rule are stated in the soldier's own readings.
* **Mana and automatic production.** Each soldier-granting building carries two auto-cast abilities, one for its soldier type and one for its worker crew, and both pay from the building's single mana pool. A cast spends one production worth of mana and starts that ability's cooldown. A finished building opens with one production worth of mana and auto-casts from the first moment it is functional. The available production count is published as the building's overhead badge, including the zero it reads when the pool cannot pay, and the building's readings - the soldier it unlocks, its mana against its maximum, its regeneration, both cooldowns, its worker profile and buff and the soldiers it maintains against its capacity - are published to the inspector through `IGameAPI.SetUnitReadoutRow`, so an opponent that selects the building reads the same numbers the owner does.
* **Capacity is a map rule.** The engine's mana pool cannot state a per-type maximum, so the ruleset counts the living soldiers of each type against the summed capacity of that player's buildings that grant it, and disables the soldier ability of every granting building while the type is full. Worker capacity is counted per building. This is why relics and hero effects that change capacity live in this map's script rather than in the engine.
* **Building supply.** A player may hold eight building locations, and every constructed building costs one point of supply. The Nexus is free and does not count. A placement that would exceed the cap is refused before the wood is spent.
* **Hero death.** Losing the hero destroys the army, clears production, and schedules a revival at the Nexus, with the timer growing by three seconds per earlier death. Revival refills every building's mana.
* **Workers.** Every finished building raises workers from its own worker profile - capacity, cooldown and production cadence, separate from the soldier profile - through its own auto-cast ability and the same mana pool as its soldiers. Each worker is the same `unit/worker` template, raised at the level of the construction order of the building that raised it: the first building's workers are level 1, the next building's level 2, and so on. Workers are attackable and are replaced through their building's worker ability when killed. Each is marked as a worker, so one player's crew keeps its spacing while another player's crew walks through it.
* **Gathering is combat.** A node's health is its remaining resource: gold mines and trees are `Harvestable`, state the item a piece of them is, state how many pieces a point of damage yields (`YieldPerDamage`), and carry armor and magic resistance from their template's per-level scaling. A worker attacks the nearest node of its assigned resource with its own attack, so damage type, penetration, critical strikes and attack speed all decide the hit; the damage that gets through the node's resistances is turned into pieces of the node's item and drawn off its health one point per piece. Both nodes yield one piece per four points of damage and resist enough of a worker's swing that the swing is worth about one piece, so a worker fills its inventory in six swings and a higher attack, penetration or node resistance moves that rate. Every unit may fill six inventory slots, which equipment and resources share: wood holds one piece per slot and gold holds six, so a full inventory is six wood or thirty-six gold, and a hero carrying relics has that many fewer slots to haul with. When the worker cannot hold another piece it walks to the nearest drop-off, spends the stack into the player's stockpile, and returns. When its node is destroyed it finds the next nearest node of the same resource. The hero gathers the same way by hand.
* **What a node is worth.** A level-1 tree line holds 800 pieces, one player's whole building supply, and a level-1 gold mine holds 600, one player's whole relic pool, so a crew left on one node runs it dry inside a match and has to reach farther. The worker's 0.8 s swing makes a six-piece wood trip six swings, about five seconds at the node, so a two-worker crew brings a building's 100 wood home in about a minute once the walk is counted, and the hero's own hit fills the same six slots in two swings.
* **Creeps and bosses.** The board places neutral monsters the way it places the nodes - four Crest Boars and one Ridge Giant on this board. They belong to no seat, fight every player, and come back where they stood, a boar after 45 seconds and the giant after two minutes, so the same camp is worth contesting more than once. Both pay their bounty to whoever lands the killing blow. A camp's template states the level its monsters stand at and the share of its bounty each level above the first adds (`LevelGrowth.BountyMultiplierPerLevel`), so the boar's 28 gold and 20 experience pay twice over at level 2 and the giant's 45 and 35 four times at level 4. A stronger camp is worth more because of its level, not because its flat bounty was written higher.
* **Worker buffs replace income rates.** Each building applies a permanent buff to the workers it raises: armor and health for the Bulwark Hall, attack for the Warband Yard and most gold buildings, move speed for the Spear Lodge and Mender Shrine, and a slow, heavy hit for the Bolt Foundry. The buff is listed on the worker's stat panel, and the building's draft tooltip states it instead of a computed income rate. A worker's gathering rate is therefore read from its own stats, level, buffs and walk rather than advertised by its building.
* **Destroyed buildings and repair.** A drafted building reduced to zero health stays on the board as a ruin instead of leaving it: it takes no more damage, accepts no deliveries, regenerates no mana and fields no soldiers, while the mana it already held is kept, and its capacity contribution stays part of its type's total. The hero mends any allied ruin at 3% of the building's maximum health per second, so every building takes the same time to raise, and the ruin only starts working again once it is whole. The building's worker stands down while the ruin waits and walks back to its node the moment the building stands. The Nexus is the exception: it is destroyed for good and never repaired. A ruin's inspector states `Destroyed (repair to restore)` where its production line normally reads.
* **The relic vendor.** Your own Nexus is the relic vendor, and it is the only completed building that opens a command grid rather than being inspection-only: six relic purchases fill its first row and half of its second, hotkeys 1 to 6, 100 gold each - front-formation health, cooldown rate, damage reflection, worker attack, tenacity and soldier production cooldown. A purchase is a cast on the Nexus, not a shop screen, and it needs a living hero, a free relic slot and the gold; the relic then sits in the hero's inventory, so relics and gathered pieces share the same six slots. The vendor greys out a relic the hero already holds and the whole grid while the hero is dead, and every relic applies player-wide while held and comes back with the revived hero, so the only decision is purchase order.
* **Innates.** Vale's whole side - hero, soldiers, workers and buildings - carries flat armor and tenacity. Sable's army applies Cinder Mark, whose burn scales from her spell power. Corvus's soldier-granting buildings store one extra production worth of mana.
* **Bulwark.** Every operational building gains armor and magic resistance from its team's Bulwark, counting its own buildings and its allies' buildings; a nearby hostile force reduces that resistance. Heroes gain it from their own nearby soldiers.
* **Free-for-all damage affinity.** A team's blows carry less against a team that is already fighting somebody else, so a third party cannot finish a fight it did not start. Damage carried before the victim's resistances is banked per pair of teams - a blow under five points is ignored - and every banked point fades with a thirty-second half life. Once a second the rules restate, for each pair at war, the share of the defender's current fight the attacker accounts for: a duel is fought at full strength, an attacker arriving on someone else's fight starts at five percent and climbs as it contributes, and two attackers splitting one defender halve each other's effectiveness unless they are also fighting each other, in which case a real three-way fight costs every side less. The reduction is read from a shield that flashes on the victim - pale at full effectiveness, deepening to blue as the reduction grows - at most once every six tenths of a second per unit.
* **Elimination.** Destroying a Nexus eliminates its player; the last team holding a Nexus wins.
* **Under-attack alerts** are throttled per player, name the victim, ping the minimap and play a warning.
* **Instant abilities.** Requisition advances the active construction and Emergency Levy adds one production worth of mana to every soldier-granting building.
* **The shared building deck.** Begin Construction places an unidentified construction site for 100 wood, picking the ground from the site's own silhouette with the standard construction placement rather than from a targeting cross-hair, and draws up to three buildings from one deck shared by every player. The draw excludes what another player already took and what the player already stands on, and a deck with nothing left is restored before it is drawn again. The three packages are the site's own command grid; the chosen one leaves the deck, the others return, and a player who abandons the draw gets the 100 wood back. The site is invulnerable and held at 99% of its construction time until a package is locked, so it can be laboured in advance and can never finish as a building nobody chose. Locking a package reveals it as that building and keeps the work already spent on it, and the site then finishes on the hero's own labour - no site advances on a clock, so a hero that never labours never finishes it - and starts its production when the engine announces the completion. While the draw is open the site states the reserved packages in its own state line, which is what an opponent reads when they select that ground.
* **Gathering and nodes.** Hero and worker gather through the same order; only the worker carries the idle-assignment tag, so a hero gathers solely when the player tells it to. A gather order plays the labor animation at the node. Trees and gold mines are selectable, show their remaining capacity and resistances, and are removed from the simulation and the board when their health reaches zero.
* **Soldier abilities.** Every soldier ability is auto-cast, and the rule it casts by is authored in `metadata.json` rather than driven by the script: Mend is `MostWoundedAlly` below 90% health, Warding Aegis is `LowestHealthAlly`, and Standard Aura is `AllyWithoutEffect`. The engine's `AutoCast.TargetRule` resolves the target, pays the ability's mana and starts its cooldown, so the script carries no per-template timer and a new healing, shielding or aura soldier needs only its metadata.
* **Instructions.** The map publishes its player-facing rules through `IGameAPI.AddInstructionsSection`, so the in-game instructions menu describes this ruleset's production, supply, gathering, relics and victory conditions without engine UI hard-coding them.

## Localization

A player reads this ruleset in the language they pick in Settings → Game → Language. The catalogs are `locale/{code}.json`, flat `{"English text": "translated text"}` files that the client merges over the game's own when the map loads, so every player reads the same match in their own language and nothing about it runs in WASM. Shipped: `es`, `fr`, `de`, `pt`, `ru`, `zh`, `ja`, `ko`, `ar` and `hi`; a missing entry reads as the English text, so no file has to be complete for a match to be readable.

What is translated: every template name and description in `metadata.json`, every feedback line the script shows a player (through `api.Translate` at the point it is shown, with `{0}` for the numbers so a translation can move them), the four instructions pages, the relic cards, the draft card tooltip - published as a `{{Ability.Key}}` template so the sentence is one key and the numbers are filled in after it - and the buff names and stat phrases the script publishes. A line the script composes at run time from a value it measures - a worker crew's name, a building's Bulwark totals, the burn a Cinder Mark is doing, the reservation note on an unidentified site - is published in English, because there is no string for a catalog to key.

`python .agent/skills/skill-translate-map/verify_keys.py verify` checks every catalog against the text `metadata.json` and the scripts hold, and `list`/`merge`/`prune` add, fill and retire entries; see `.agent/skills/skill-translate-map/SKILL.md`.
